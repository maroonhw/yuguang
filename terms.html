予光服务条款

最后更新:2026-05-14  ·  生效日期:2026-05-14

本服务条款("本条款")是您("用户"或"您")与予光应用("予光"或"我们")之间关于使用予光 iOS 应用程序及相关服务(统称"本服务")的法律协议。

请您在使用本服务前仔细阅读本条款。一旦您下载、安装、登录或使用本服务,即视为您已完整阅读、理解并同意本条款的全部内容。 如果您不同意,请不要使用本服务。

本条款配套《隐私政策》一同适用。如有冲突,以《隐私政策》为准。

一、服务概述

予光是一款让两位已互加联系人的用户在对方桌面 widget 上互相留言的私密 iOS App。

主要能力(1.0):

  • 发送文字 + 图片便签(单条);
  • 选择立即显形或时间胶囊(指定未来某时刻解锁,前后双方均不可读);
  • 收件人桌面 widget 自动更新;
  • 桌面停留 7 天后自动隐藏,详情页长期保留(直至您主动删除或注销账号);
  • 仅互加为联系人(mutual)的两个用户之间可互发,无公开广场、无陌生人推送。
重要说明:便签明文存储
予光早期版本曾规划端到端加密(E2E),后已取消。本版本(1.0)便签内容(文字、图片)以明文形式存储于运营方服务器(中国上海腾讯云 CloudBase)。运营方在《隐私政策》中承诺不主动读取,但技术上具备读取能力。请您据此评估是否使用本服务发送敏感内容。

二、账号

2.1 注册与登录

本服务仅支持使用 Apple ID 通过"通过 Apple 登录"(Sign in with Apple)注册和登录。我们不收集您的邮箱、电话号码或真实姓名(Apple 提供"隐藏邮箱"选项,亦兼容)。

2.2 账号安全

您应对您账号下发生的所有活动负责。如果您发现 Apple ID 被盗用,请立即在 Apple 系统中处理;予光账号会随之失效。

2.3 一人一号 / 单设备登录

  • 每个 Apple ID 对应一个予光账号;
  • 同一账号同一时刻仅可登录一台设备;新设备登录会自动登出旧设备;
  • 我们不允许使用脚本、模拟器或其它自动化手段批量注册账号。

2.4 账号注销

您可以随时在「我 → 设置 → 注销账号」中注销您的账号。注销后:

  • 立即生效:您将被退出所有设备,您的资料在联系人列表中显示为「已注销用户」,未送达的时间胶囊不再发送,您发出的未显形便签明文立即清除;
  • 7 天宽限期:重新使用同一 Apple ID 登录可恢复账号;
  • 超过 7 天后,您的账号、便签记录、邀请记录将被物理删除,无法找回。

三、使用规则

3.1 您不得

通过本服务发送、传播、储存以下内容或从事以下行为:

  • 违反中华人民共和国法律法规的内容(涉黄、涉政、涉暴、涉恐、涉赌博、涉违法广告等);
  • 骚扰、辱骂、恐吓、仇恨、歧视、欺诈、人肉搜索、侵犯他人合法权益的内容;
  • 色情、淫秽、低俗的图片或文字;
  • 未经他人同意获取或公开他人的个人信息;
  • 冒充他人身份(包括但不限于冒充客服、亲友、公众人物);
  • 通过技术手段干扰、破坏、绕过本服务的正常运行(例如绕过单设备登录、批量注册、爬取数据);
  • 对本服务或其客户端代码进行反向工程、破解、修改;
  • 利用本服务实施任何商业广告、诈骗、传销活动。

3.2 内容审核

为遵守 Apple App Store Guideline 1.2 / 4.3 及中国相关法规,本服务采取以下措施:

  • 图片自动过滤(本地):发送图片时,客户端通过 Apple 系统的 SensitiveContentAnalysis 框架在您设备本地自动检测,涉嫌敏感内容的图片会被阻止上传;
  • 用户举报:任意便签卡片支持「举报违规」入口,可一键通过系统邮件向我们举报;
  • 拉黑联系人:您可随时在联系人页面拉黑对方,即时生效;
  • 处置承诺:我们承诺在收到举报后 24 小时内核实并处置违规内容/账号(下架、警告、临时封禁、永久封禁、配合执法等)。

3.3 不可挽回操作的提示

  • 时间胶囊密封后,在解锁前的有限时间窗口内可撤回(具体由产品决定),密封是承诺式操作,请您在密封前确认内容;
  • 撤回:已撤回的便签明文立即从服务端清除,无法恢复;
  • 删除联系人:删除后,您与对方之间的所有联系记录归零;若想恢复需重新走邀请流程。

3.4 未成年人

  • 本服务不专门面向 14 岁以下儿童(根据《个人信息保护法》);
  • 若您未满 18 岁,请在监护人指导下使用本服务;
  • 若您是未成年人的监护人,发现孩子在未经您许可的情况下注册使用本服务,请通过 §8 联系我们,我们将协助删除其账号。
